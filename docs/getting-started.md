# Getting Started

Install `@goobits/forms`, `@goobits/goo`, and `zod`. Configure contact categories once on the server, mount `createContactApiHandler` in a SvelteKit endpoint, then render `ContactForm` from `@goobits/forms/ui`.

The complete minimal example is in the package [README](../README.md#contact-form). Use `@goobits/forms/core` for smaller newsletter, waitlist, and preference forms that do not need the contact workflow.
