# TypeScript

Use `FormValidationResult<T>` for normalized validation, `FormSubmissionState<T>` for UI state, and `FormActionOptions<TData, TResult>` for SvelteKit actions.

```ts
import type { FormSubmissionState, FormValidationResult } from '@goobits/forms/core';
```

Contact configuration and schema types are exported from `@goobits/forms/config` and `@goobits/forms/validation`.
